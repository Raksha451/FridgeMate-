# 🥗 FridgeMate - AI-Powered Food Management

### Manage Your Food Smarter. Reduce Waste. Discover Recipes.

FridgeMate is an AI-powered application prototype designed to help users manage food inventory, monitor expiry dates, and discover recipe suggestions. By combining food management with AI-assisted capabilities, the project aims to encourage smarter food consumption and reduce household food waste.

Built using **Google AI Studio and Google's Gemini API**, FridgeMate explores how AI can make everyday kitchen management more convenient.

## 🎯 Problem Statement

Households often struggle to keep track of stored food items, remember expiry dates, and decide what meals to prepare using available ingredients. This can result in unnecessary grocery purchases and avoidable food waste.

FridgeMate aims to address these challenges by bringing food inventory management and recipe discovery into one convenient application.

## ✨ Key Features

- **🧊 Food Inventory Management** - Keep track of food items stored at home.
- **⏰ Expiry Date Monitoring** - Track expiry dates to help prioritize food that should be used soon.
- **🍳 AI-Powered Recipe Suggestions** - Discover meal ideas based on available ingredients.
- **♻️ Food Waste Reduction** - Encourage better food utilization and responsible consumption.
- **🤖 AI Integration** - Explore the use of Google's Gemini models in a practical application.
- **📱 Interactive User Experience** - Access food management functionality through a digital interface.

## 🚀 Getting Started

Follow these steps to run the application locally.

### Prerequisites

- Node.js
- npm
- A Google Gemini API key

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Raksha451/FridgeMate-.git
```

**2. Navigate to the project directory**

```bash
cd FridgeMate-
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure your API key**

Create a `.env.local` file in the project root and configure your Gemini API key:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Replace `your_gemini_api_key` with your actual API key. Never commit real API keys or other secrets to GitHub.

**5. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.
